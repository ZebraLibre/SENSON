# Pasta de ROMs do SNES

Coloque aqui os seus arquivos de jogos do Super Nintendo no formato `.sfc` ou `.smc`.

### Nomes dos arquivos esperados pelo menu padrão:
- `super-metroid.sfc`  (Super Metroid - Jogo Principal)
- `super-mario-world.sfc`  (Super Mario World)
- `megaman-x2.sfc`  (Mega Man X2)
- `megaman-x3.sfc`  (Mega Man X3)
- `cybernator.sfc`  (Cybernator)

> **Nota:** Certifique-se de que os nomes dos arquivos sejam exatamente iguais aos listados acima (com letras minúsculas e hífen), ou ajuste a lista no arquivo `app.js`.
